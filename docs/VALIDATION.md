已执行：

- 7 个主工具契约、旧质量工具兼容注册及原 3 个 Python 脚本语法检查。
- 实际加载 DDSP 与 GPT-SoVITS 后端，核对可用操作及参数 schema；拒绝错误参数、未知路线和推理/翻唱/发布操作。
- 成功/失败均保留后端原始结果与统一回执；预览不执行、不创建执行回执；显式错误工程路径不回退。
- 番剧 JSONL / train.list 到训练台词的实际文件桥接，验证音频存在、原文和时间保留、角色选择、空结果及不覆盖已有清单。
- 番剧运行适配器的结构化 argv、离线模型要求、输出文件核查。模型执行使用 mock，退出码 0 但无产物会失败。
- 本地真实 Python / FFmpeg、只使用合成 PCM WAV：DDSP 扫描与出料 2 条；番剧字段桥接后，GPT-SoVITS 扫描与出料 2 条；输出为 32kHz 单声道，原台词保留，回执写盘。
- 固定来源清单逐文件 SHA-256 核查。GSV 扫描器的精确 voice_path 兼容修正单独记录 patchedSha256，出料器本身已支持此字段。

本轮没有执行完整 GPU 训练、真实番剧的分离/ASR/声纹流程、推理试听或主观音质验收。模型注册仍沿用后端的文件检查，不等同音质验收；RVC 训练未接入。

本机跨采样率 DDSP 测试曾在上游可选 librosa/Numba 路径耗时异常，已停止该测试。最终 DDSP 夹具使用原生 44.1kHz 验证连接、留尾与出料；跨采样率性能未在本轮验收，不能用本测试宣称已验证该依赖路径。GPT-SoVITS 的 FFmpeg 重采样至 32kHz 已实际通过。

仓库快照/适配测试验证的是可调用的整合实现，不能替代特定用户机器上完整训练任务的验收。宿主实际长任务调度仍需以用户环境的进程、日志和真实模型记录为准。
